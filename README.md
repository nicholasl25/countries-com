# Countries.COM

Countries.COM is a country-explorer product: browse countries, compare key facts, and dig into place context in one place.

## Status

Repository bootstrap only. The application has not been built yet.

## Run (once built)

After the app is scaffolded, start the local development server from the repo root and open the URL printed in the terminal. Exact commands will land in this README when the first app slice ships.
